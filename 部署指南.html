1创建飞书开发者应用
  1. 打开飞书开放平台：https://open.feishu.cn/app
  2. 点击「创建企业自建应用」
  3. 填写应用名称（如：物流工作台）和描述
  4. 应用图标可上传任意图片，点击「创建」
需要使用飞书管理员账号操作。如果不是管理员，请联系管理员协助创建。
2配置应用权限

应用创建后，进入「权限管理」页面，添加以下权限：

必须添加的权限

权限名称权限标识用途
查看多维表格bitable:app:readonly读取表格数据
编辑多维表格bitable:app写入/修改/删除数据

操作步骤

  1. 在应用详情页左侧菜单点击「权限管理」
  2. 搜索 bitable，找到上述两个权限
  3. 分别点击「开通」
  4. 完成后点击页面上方的「批量开通」确认
权限添加后需要管理员审批生效。如果自己是管理员，审批会自动通过。
3获取应用凭证

在应用详情页的「凭证与基础信息」中获取：

  • App ID：格式如 cli_a1b2c3d4e5f6g7h8
  • App Secret：一串随机字符串，点击「显示」后可见
App Secret 是敏感信息，请妥善保管，不要泄露给无关人员。
4配置后端环境变量

方式 A：TRAE 环境（自动认证）

在 TRAE 环境中，飞书用户访问令牌会自动注入，无需手动配置 App Secret。

只需确保 FEISHU_BASE_TOKEN 正确即可，服务启动后自动使用用户令牌认证。

方式 B：生产环境（App ID + Secret）

在工作台项目的 server/ 目录下创建 .env 文件：

# 复制示例文件
cp server/.env.example server/.env

# 然后编辑 .env 文件，填入你的凭证
FEISHU_APP_ID=cli_a1b2c3d4e5f6g7h8
FEISHU_APP_SECRET=你的AppSecret
FEISHU_BASE_TOKEN=JOKzbxJdlaKGz0sUlsnckcb76Fi
PORT=3000
FEISHU_BASE_TOKEN 已预填好，这是已创建的飞书多维表格 ID，无需修改。 服务支持双重认证：优先使用环境中的用户令牌，其次使用 App ID + Secret 获取 tenant_access_token。
5部署后端服务

方式 A：Docker 部署（推荐）

# 在项目根目录执行
bash start.sh

# 或者手动操作
docker compose up -d --build

# 查看运行日志
docker compose logs -f

# 停止服务
docker compose down

启动后访问 http://localhost:8080（端口映射 8080 → 3000）。

方式 B：Node.js 直接运行

# 进入 server 目录
cd server

# 安装依赖（首次运行）
npm install

# 启动服务
node server.js

# 或者用 start.sh 脚本
bash ../start.sh

启动后访问 http://localhost:3000。

方式 C：仅前端模式（无同步）

如果未配置飞书凭证或未安装 Node.js/Docker，工作台会自动降级为本地模式：

# 使用 Python
python3 -m http.server 8080

此模式下数据仅保存在浏览器本地，无法多人共享同步。

部署到服务器时，请确保 3000 端口（或映射后的端口）可被外部访问。 如果使用反向代理（如 Nginx），需要将 API 请求代理到后端服务。
6嵌入飞书云文档

后端服务运行后，可以将工作台嵌入飞书云文档中，方便团队成员访问：

方法 1：嵌入飞书文档

  1. 在飞书中新建一个文档（或打开已有文档）
  2. 在文档中输入 / 打开命令面板
  3. 搜索并选择「嵌入网页」
  4. 输入工作台访问地址（如 http://your-server:8080）
  5. 点击「嵌入」

方法 2：分享链接

  1. 确保工作台服务已部署并可通过网络访问
  2. 将访问地址分享给团队成员
  3. 团队成员在浏览器中打开即可使用
嵌入飞书文档时，如果服务部署在内网，飞书客户端需要能访问到该地址。 如果部署在公网服务器上，则任何有链接的人都可以访问。
7验证同步功能
  1. 打开工作台，右上角应显示绿色「已同步」徽章
  2. 如果显示灰色「本地模式」，说明后端未启动或凭证未配置
  3. 如果显示红色「同步失败」，检查后端日志和飞书应用权限
  4. 在工作台新增一条记录，然后在飞书多维表格中确认数据已同步
  5. 在另一个浏览器/设备上打开工作台，确认能看到刚才新增的数据
如果以上步骤全部通过，说明同步功能已正常工作！所有用户的数据变更将实时同步到飞书多维表格，多人共享同一份数据。
常见问题排查

1. 徽章显示「本地模式」

  • 检查后端服务是否正在运行：docker compose ps 或 ps aux | grep node
  • 检查 .env 文件中的 FEISHU_APP_ID 和 FEISHU_APP_SECRET 是否已正确填写
  • 打开浏览器控制台（F12），查看 Network 请求 /api/status 的响应

2. 徽章显示「同步失败」

  • 查看后端控制台日志，检查错误信息
  • 确认飞书应用权限已添加并审批通过
  • 确认 FEISHU_BASE_TOKEN 正确（多维表格 URL 中 /base/ 后的部分）
  • 确认飞书应用已被添加为多维表格的协作者（在多维表格右上角「...」→「更多」→「添加协作者」中添加应用）

3. 数据未同步到飞书

  • 检查浏览器控制台是否有 [API] 开头的错误日志
  • 确认应用有 bitable:app（编辑多维表格）权限
  • 在飞书多维表格中直接查看数据是否已写入

4. 嵌入飞书文档后无法访问

  • 飞书嵌入网页要求目标地址支持 HTTPS（生产环境）
  • 如果是内网地址，确保飞书客户端与服务器在同一网络
  • 检查服务器防火墙是否放行对应端口

5. 添加飞书应用为多维表格协作者

飞书应用需要被添加为多维表格的协作者才能读写数据：

  1. 打开飞书多维表格
  2. 点击右上角「...」→「更多」→「添加协作者」
  3. 搜索你的应用名称（如「物流工作台」）
  4. 添加为协作者，权限选择「可编辑」
